# Weed Watch

Weed Watch is an FLL innovation-project prototype that helps a community:

1. Photograph a possible weed.
2. Review an on-device prototype result.
3. Create a digital cleanup flag.
4. Let an adult volunteer confirm and safely remove the plant.

The image result is not professional botanical advice. Never touch or eat an
unknown plant, and always ask an adult to confirm a report before removal.
